# Baseline condition

Use the pre-change autonomous RPI workflow:

- Decompose the supplied question into numbered sub-questions.
- Draft research under `research-deep`, validate it, and run one generic fresh-context reviewer pass over the draft and template criteria.
- Draft a plan citing the research and run correctness plus implementability reviewer passes.
- Do not use a draft-blind coverage scout, a separate evidence-verifier role, or `comments analyze`.
- Return the research doc, plan doc, open human threads, and semantic pass count.
